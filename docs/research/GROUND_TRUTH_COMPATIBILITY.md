# Ground-Truth Compatibility v0.1.0

Sprint 1 defines `GroundTruthContext` so ACRA-Lab can supply known:

- principal
- role
- tenant
- resource
- owner
- action
- expected authorization decision
- workflow state
- vulnerable/secure case classification

The model is compile/test verified by a `GT-BOLA-001` fixture. No precision, recall, F1, true-positive, or false-positive result is claimed because no evaluation dataset has been executed yet.
