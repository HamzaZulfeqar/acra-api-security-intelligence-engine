# ADR-0001: Core Platform Runtime and Language

**Status:** ACCEPTED  
**Decision:** Java 21 LTS for `acra-core` v0.x  
**Accepted in:** Sprint 1

## Context

Sprint 1 requires an executable standalone deterministic core. A later Burp adapter must integrate without moving domain logic into Montoya-specific code.

## Decision drivers

- deterministic immutable domain modelling
- strong standard library and JVM tooling
- future zero-IPC Burp adapter compatibility
- straightforward unit/security testing
- portability across lab, Burp, CI, and research tooling
- ability to keep the core independent of Burp packages

## Options considered

- Java 21 LTS
- Rust with an IPC boundary
- Go with an IPC boundary
- hybrid JVM/native design

## Decision

Use Java 21 LTS for the v0.x ACRA core. Burp-specific APIs remain outside `acra-core`.

## Consequences

- Sprint 1 can compile using only the JDK.
- Future non-JVM adapters may require a separate interface/IPC ADR.
- This does not select an exact Burp or Montoya version.
- This decision may be superseded if benchmark or integration evidence demonstrates a material limitation.
