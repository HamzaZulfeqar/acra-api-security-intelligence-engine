# ADR-0031: Deterministic Security Decision and AI Boundary

**Status:** ACCEPTED  
**Decision:** AI output is non-authoritative for vulnerability classification  
**Accepted in:** Sprint 1

## Invariant

Deterministic components own graph traversal, state comparison, structural comparison, evidence validation, and security-decision state transitions.

AI-assisted components may later help with endpoint classification, workflow inference, explanation, or remediation suggestions, but a vulnerability must never be reported solely because an LLM predicted it. A verified HTTP/evidence trace is required by the finding pipeline.

Sprint 1 contains no LLM decision path.
