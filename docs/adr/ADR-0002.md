# ADR-0002: Security Context Graph Representation

**Status:** ACCEPTED  
**Decision:** Memory-first directed adjacency-list graph with explicit evidence registry  
**Accepted in:** Sprint 1

## Context

Sprint 1 requires direct contextual relationship queries but does not require durable graph persistence.

## Decision

Implement `SecurityContextGraph` as a deterministic in-memory directed graph:

- nodes keyed by stable string IDs
- edges keyed by deterministic edge IDs
- outgoing adjacency sets keyed by source node
- separate evidence registry
- every edge must reference evidence IDs already present in the graph
- direct queries must avoid whole-graph traversal when an adjacency lookup is sufficient

## Consequences

This satisfies Sprint 1 provenance and direct-neighbor requirements while leaving persistent graph representation under ADR-0003 open. No sub-millisecond performance claim is made.
