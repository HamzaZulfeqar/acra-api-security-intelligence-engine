# ADR-0026: PII and Secret Sanitization Strategy

**Status:** ACCEPTED FOR SPRINT 1 CORE  
**Decision:** Universal serialization redaction plus SHA-256 correlation fingerprints  
**Accepted in:** Sprint 1

## Decision

- raw bearer/API/session credentials may exist transiently in the in-memory HTTP request model when received from an authorized source
- domain identity/session correlation persists SHA-256 fingerprints instead of raw tokens
- deterministic serialization redacts sensitive headers and cookie values
- raw HTTP byte arrays are represented in persisted serialization by length and SHA-256 digest, not raw bytes
- known credential-bearing body fields and bearer/JWT-like strings pass through the redactor

## Limitations

This does not select encrypted workspace storage or SQLite. Those remain separate persistence decisions. SHA-256 fingerprints are correlation identifiers, not encryption.
