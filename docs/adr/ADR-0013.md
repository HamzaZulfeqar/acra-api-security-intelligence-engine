# ADR-0013: Initial Protocol Scope

**Status:** ACCEPTED  
**Decision:** REST/HTTP is the v0.x baseline domain target; future protocol families remain plugin scope  
**Accepted in:** Sprint 1

## Decision

Sprint 1 models generic HTTP transactions and REST-style URI/resource context. GraphQL, gRPC, WebSockets, OAuth/OIDC-specific analysis, and webhooks are not implemented in Sprint 1. Interfaces must not prevent future parsers/plugins for those families.

## Consequences

The core is not labelled a GraphQL, gRPC, WebSocket, or OAuth security engine in v0.1.0.
