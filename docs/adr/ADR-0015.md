# ADR-0015: Initial Confidence Model

**Status:** ACCEPTED  
**Decision:** Deterministic engineering confidence bands for v0.1.0  
**Accepted in:** Sprint 1

## Decision

Use these initial engineering values:

| Basis | Score |
|---|---:|
| EXACT_OBSERVED | 1.00 |
| EXPLICIT_METADATA | 0.95 |
| STRUCTURAL_INFERENCE | 0.80 |
| HEURISTIC | 0.60 |
| WEAK_HEURISTIC | 0.30 |
| UNKNOWN | 0.00 |

## Research limitation

These values are engineering heuristics, not calibrated probabilities and not scientific findings. Later experiments may supersede them.
