# ADR-0006: Burp Suite and Montoya Compatibility Baseline

**Status:** ACCEPTED  
**Decision:** Target PortSwigger Montoya API `2026.7`; validate release promotion against Burp Suite Professional/Community `2026.7.3` Stable.

## Context

Sprint 2 introduces the first Burp-specific adapter while `acra-core` must remain Montoya-free. A concrete compile/runtime compatibility baseline is therefore required.

As of Sprint 2 review on 2026-08-31:

- PortSwigger publishes Montoya API artifact `net.portswigger.burp.extensions:montoya-api:2026.7`.
- Burp Suite Professional/Community `2026.7.3`, published 2026-08-06, is the current stable desktop line identified for the release gate.
- Burp Suite `2026.8`, published 2026-08-24, is an Early Adopter release and is not the Sprint 2 stable release gate.

## Decision drivers

- current official Montoya contracts
- stable Burp target for reproducible validation
- separation of Burp adapter from core
- deterministic extension bootstrap and unload
- future compatibility testing

## Decision

1. Compile/package the Burp adapter against Montoya API `2026.7` with scope `provided`.
2. Keep every `burp.api.montoya` type outside `acra-core`.
3. Treat successful load/traffic/UI validation in Burp Suite Professional/Community `2026.7.3` Stable as the Sprint 2 release promotion gate.
4. Early Adopter `2026.8` compatibility is optional follow-up evidence and is not required to promote Sprint 2.
5. Local contract stubs may be used only when official artifacts are unavailable to the execution environment. Stub compilation is not equivalent to Burp runtime validation.

## Verification state

- Montoya contract-shaped compilation: **VERIFIED locally via narrow test stubs**.
- Official Maven artifact resolution: **UNVERIFIED in current execution environment** because Maven/network access is unavailable.
- Real Burp extension load: **BLOCKED / UNVERIFIED** because Burp Suite is unavailable in the execution environment.

## Consequences

Sprint 2 remains a release candidate until the real Burp gate is executed and evidence is committed.
