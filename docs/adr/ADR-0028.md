# ADR-0028: Core and Adapter Boundary

**Status:** ACCEPTED  
**Decision:** In-process Java contracts for v0.x core, with no Burp dependency in `acra-core`  
**Accepted in:** Sprint 1

## Decision

`acra-core` exposes Java domain/extraction/plugin interfaces. Burp, lab, experiment, CLI, or future protocol adapters translate external data into core domain objects. No Montoya package is permitted inside the Sprint 1 core source tree.

A future cross-process IPC/gRPC contract requires a new or superseding ADR.
