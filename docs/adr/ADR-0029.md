# ADR-0029: Schema Versioning Strategy

**Status:** ACCEPTED  
**Decision:** Explicit canonical JSON schema version beginning at `1.0`  
**Accepted in:** Sprint 1

## Decision

`DomainSerializer` emits a stable root envelope containing:

- `schemaVersion`
- `type`
- `data`

Map keys are sorted and field names are stable. Breaking serialization changes require a schema-version change and migration/compatibility note.
