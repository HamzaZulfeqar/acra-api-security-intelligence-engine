# ADR-0032: Sprint 2 Minimal Integration Lab Fixture

**Status:** ACCEPTED  
**Decision:** Use dependency-free Python 3.13 HTTP services plus Docker Compose descriptors for the Sprint 2 integration fixture only.

## Context

Sprint 2 requires a deterministic live HTTP target so the traffic intelligence pipeline can be exercised against known principal, tenant, resource, and action ground truth. The long-term ACRA-Lab framework decision in ADR-0008 remains OPEN.

## Decision

- Sprint 2 basic secure/vulnerable fixture services use Python 3.13 standard-library HTTP servers.
- Docker Compose describes reproducible local service topology.
- Direct Python execution is an allowed verification fallback when Docker is unavailable.
- The Sprint 2 experiment uses benign same-tenant requests and does not exploit the intentionally vulnerable fixture.

## Consequences

This ADR does **not** select the long-term ACRA-Lab application framework, database, gateway, or authentication stack. ADR-0008 through ADR-0012 remain OPEN where applicable.
