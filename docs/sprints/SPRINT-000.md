# Sprint 0: Engineering Foundation

## Goal

Convert RB-0 into repository-controlled requirements, architecture contracts, safety controls, schemas, ADRs, test traceability, ground-truth methodology, experiment methodology, and development gates.

## In scope

- requirements baseline
- architecture boundaries
- threat model
- security model
- A-Z test taxonomy
- technology-neutral data model
- adapter/API contracts
- ACRA-Lab specification
- baseline and ablation methodology
- novelty ledger
- project-state governance
- ADR system
- CI and repository gate skeletons

## Out of scope

- production scanner implementation
- live Burp integration
- completed ACRA-Lab application
- completed GUI
- real experimental metrics
- novelty claims presented as proven

## Definition of done

Sprint 0 is complete only when required repository artifacts exist, unresolved choices are represented as OPEN ADRs, cross-document traceability is consistent, and the next sprint can proceed without relying on prior chat history.
