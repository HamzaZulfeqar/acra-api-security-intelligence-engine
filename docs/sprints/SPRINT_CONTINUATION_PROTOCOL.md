# Sprint Continuation Protocol

For every future repository ZIP:

```text
Repository intake
  -> integrity inspection
  -> PROJECT_STATE inspection
  -> current sprint inspection
  -> architecture and ADR inspection
  -> source inspection
  -> test inspection
  -> previous-sprint verification
  -> technical-debt review
  -> next-sprint implementation
  -> verification
  -> documentation update
  -> new canonical repository package
```

If documentation and implementation disagree, repository reality must be recorded accurately and the state documents corrected.
