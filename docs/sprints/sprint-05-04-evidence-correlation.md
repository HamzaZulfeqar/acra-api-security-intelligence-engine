# S5-04 Evidence Correlation

S5-04 adds deterministic correlation of BOLA and BFLA assessments.

## Boundary
This layer aggregates authorization assessments. It does not create confirmed findings.

## States
CORROBORATED, CONSISTENT, DUPLICATE, CONFLICTING, INSUFFICIENT, INCONCLUSIVE.

## Provenance
Existing assessment, observation, execution and evidence identifiers are preserved.
