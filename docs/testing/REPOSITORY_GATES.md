# Repository Gates

Future implementation sprints use the following gates:

1. BUILD
2. UNIT TEST
3. INTEGRATION TEST
4. SECURITY TEST
5. BURP VALIDATION
6. LIVE LAB VALIDATION
7. DOCUMENTATION
8. RESEARCH RECORD

Allowed states include `UNVERIFIED`, `FAILED`, `PARTIAL`, `BLOCKED`, and `VERIFIED`.

Sprint 0 substitutes specification-consistency and traceability reviews where executable implementation does not yet exist.
