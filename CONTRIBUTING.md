# Contributing

All contributions must preserve RB-0 and the repository-as-source-of-truth workflow.

Before modifying the project:

1. Read `sprint-status.md`.
2. Read the current sprint specification under `docs/sprints/`.
3. Review applicable architecture and ADR documents.
4. Inspect existing implementation and tests.
5. Do not assume undocumented features exist.
6. Add or update tests for implementation changes.
7. Update documentation and project state before completion.

Unresolved architecture choices must remain OPEN until an ADR is accepted.
