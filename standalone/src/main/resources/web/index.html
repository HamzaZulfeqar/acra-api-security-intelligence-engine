Review states

VALIDATED → CONFIRMEDIndependent confirmation requires new evidence. Direct candidate-to-confirmed promotion is rejected.
FALSE_POSITIVEExplicit terminal disposition when reviewed evidence disproves the candidate.
ACCEPTED_RISKTerminal risk disposition available only after CONFIRMED.
